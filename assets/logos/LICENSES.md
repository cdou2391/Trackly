# Service logos

Bundled so the app works offline. Each file is named after the catalog key that
points at it (`logo_key` in the database).

## Sources and licenses

Both collections are released under **CC0 1.0 Universal** (public domain
dedication), so the files can be used and redistributed freely.

- **gilbarbara/logos** — https://github.com/gilbarbara/logos (CC0 1.0)
- **Simple Icons** — https://github.com/simple-icons/simple-icons (CC0 1.0).
  These are single-colour marks; the official brand colour from the project's
  `simple-icons.json` has been applied as the fill.
